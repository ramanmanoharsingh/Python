# Python

Nineteen Python programs covering core fundamentals: input and output, arithmetic, conditionals, loops and small menu-driven programs such as a billing system, a movie booking flow and an ATM simulator.

Each program is a single self-contained script with no external dependencies. A recorded sample run sits next to every script, and the original assignment documents are kept in `docs/`.

## Run a program

You need Python 3. From the repository root:

```bash
python assignments/q01_expression_value.py
```

Each script asks for its input in the terminal. The files in `sample-runs/` show the prompts together with the values that were typed, so you can compare your own run against them.

## Repository layout

```text
assignments/   the 19 scripts, one per question
sample-runs/   recorded input and output for each script
docs/          original assignment documents (code and outputs)
```

## Concepts practised

- Reading input with `input()` and converting types
- Arithmetic and formulas
- `if` / `elif` / `else` decision making
- `while` loops and menu-driven flows
- Formatting output with `print()`
